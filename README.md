# AutoKitMIPS — LAN2100

**Проєкт для штатної магнітоли LAN2100 на Windows CE 5.0 / MIPSII.**

Мета — автономна робота з USB-адаптером Carlinkit і подальша інтеграція CarPlay. Проєкт перебуває в розробці.

[English](#english) · [Допомога з USBware](https://github.com/debeliakvitalii-ux/AutoKitMIPS-LAN2100/issues/1)

## Кого шукаємо

Запрошуємо розробників із досвідом:

- Windows CE 5.0 та MIPSII;
- Jungo USBware HOST;
- вбудованих USB host-драйверів;
- інтеграції автомобільних мультимедійних систем.

## Де потрібна допомога

Основний напрям — інтерфейс для USB control transfers через штатний Jungo USBware HOST **3.5.14.64** на платформі **LGE_AU1350_YN / CE5 / MIPSII**.

Корисними будуть відповідні цій платформі SDK/API-документація, приклади інтеграції host-клієнта та матеріали щодо отримання device handle, завершення передач, timeout/cancel і життєвого циклу підключення.

Якщо маєте такий досвід або матеріали, напишіть у [завданні про USBware](https://github.com/debeliakvitalii-ux/AutoKitMIPS-LAN2100/issues/1). Укажіть підтримувану версію, платформу та походження матеріалу.

## Як долучитися

Відкрийте Issue з пропозицією допомоги або технічним запитанням. Для матеріалів і коду зберігайте інформацію про походження та відповідні ліцензії.

Цей репозиторій наразі містить публічний опис проєкту й запит на співпрацю. Повне дерево програми та готовий реліз тут ще не опубліковані.

## English

### AutoKitMIPS for LAN2100

A project targeting the LAN2100 head unit running **Windows CE 5.0 / MIPSII**, with the goal of autonomous operation with a Carlinkit USB adapter and subsequent CarPlay integration. The project is under development.

### Contributors wanted

We welcome developers experienced in Windows CE, MIPS, Jungo USBware HOST, embedded USB host drivers and automotive multimedia systems.

The main area where help is needed is an interface for USB control transfers through **Jungo USBware HOST 3.5.14.64** on **LGE_AU1350_YN / CE5 / MIPSII**.

Useful contributions include platform-matched SDK/API documentation, host-client integration examples, and information about device-handle acquisition, transfer completion, timeout/cancellation and connection lifetime.

Please respond in the [USBware collaboration issue](https://github.com/debeliakvitalii-ux/AutoKitMIPS-LAN2100/issues/1), identifying the supported platform/version and material provenance. Preserve applicable licenses when sharing code or documentation.

This repository currently hosts the public project overview and collaboration request. The complete application source tree and a finished release are not yet published here.
